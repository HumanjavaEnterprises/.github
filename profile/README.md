# Humanjava Enterprises

Frontier AI and software you can hold, inspect, and run yourself.

Humanjava Enterprises Inc. (est. 2004, British Columbia, Canada) does UX research, service design, and agentic platform engineering for teams in banking, government, and health, and ships its own open tools and models.

- **Consulting:** [UX research, service design, facilitation, and agentic engineering](https://humanjava.com/consulting/services/), from the first interview to a shipped build.
- **Open models:** [DeepSeek-V4.1-Flash builds that run on stock llama.cpp](https://huggingface.co/HumanjavaEnterprises), with the [repack tool and pipeline](https://github.com/HumanjavaEnterprises/deepseek-v41-upstream).
- **Open tools:** [LSDub](https://github.com/HumanjavaEnterprises/comfyui-lsdub) for AI music-video lip-sync, [NostrKey](https://github.com/HumanjavaEnterprises/nostrkey.browser.plugin.src) and [LoginWithNostr](https://github.com/HumanjavaEnterprises/loginwithnostr) for keys you own, and a [Nostr TypeScript library](https://www.npmjs.com/~vveerrgg).
- **Writing:** [humanjava.com/articles](https://humanjava.com/articles/)
